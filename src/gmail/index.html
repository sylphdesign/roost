Connect Gmail

Google blocks its normal sign-in inside desktop apps, so Roost uses Google's official Gmail connection instead. You create your own free key once. It takes about 10 minutes, and nobody else sees your mail.

  1. Create a project Open Google Cloud Console and create a new project (any name).
  2. Enable the Gmail API Make sure your new project is selected, then click Enable.
  3. Set up the consent screen In “Google Auth Platform”, choose External and fill in an app name and your email. Under Audience, add your Gmail address(es) as Test users. Leave Data Access empty: Roost asks for Gmail access when you sign in.
  4. Create credentials Click Create client, choose Application type Desktop app, then copy the Client ID and Client secret.

One key works for all your Gmail accounts. While the app is in Testing mode Google asks you to sign in again every 7 days.

Sign in to Gmail

Your browser opens so you can sign in with Google. Then come back here.

Finish signing in in your browser…

If Google says “Access blocked … has not completed the Google verification process”, add this Gmail address under Test users in your Google Cloud project, then try again. If Google says “Google hasn’t verified this app”, that is normal for your own key: click Continue (or Advanced → Go to … (unsafe), then Continue). Tick every permission box.
