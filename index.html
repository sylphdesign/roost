What you get

Everything in one place.
Nothing in your way.

Gmail, the way you like it

Inbox tabs — Primary, Promotions, Social, Updates, Forums — just like Gmail. Read, reply, archive, star. Images load by default; scripts stay blocked.

  • Uses Google's official Gmail API
  • Many accounts, each separate
  • Optional AI help with your own Claude key

Clear out in seconds

Delete or archive from the list without opening anything. Tick a few emails — or all of them — and act on the whole group.

  • x tick · e archive · # delete
  • Undo for archive

Search every inbox at once

Press ⌘⇧F and type. Results come back grouped by inbox; press Enter to open the email where it lives. Gmail search words like from: and has:attachment work too.

Your calendar follows your inbox

Calendar, Keep, Drive and Docs sit in the top bar and open as the account of the inbox you're in. Event reminders arrive ten minutes before.

Read in full view

Hide the list with \ for a calm, full-width email. Or open emails next to the list, under it, or full screen — your choice.

Make it yours

List width, compact rows, preview text, the labels column, quiet hours, quiet during calls, per-app notifications, and your own icon for every inbox.

Keyboard first

Every action has a key, and a slim bar at the bottom shows the ones that matter right now. Press ⌘/ for the full list.

Private by design.

No Roost server. No ads. No tracking.

Your keys stay on your Mac.

Sign-ins are encrypted with the macOS Keychain. Roost talks only to Google — and to Anthropic only if you add a Claude key and click an AI button.

Get started

Build it in five commands.

Needs a Mac with Apple Silicon, Node.js 20+ and Xcode Command Line Tools.

git clone https://github.com/sylphdesign/roost.git
cd roost
npm install
npm run pack
cp -R dist/mac-arm64/Roost.app /Applications/
