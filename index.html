Roost

Every conversation comes home.

Roost is a personal desktop app for macOS. It puts Gmail, Google Calendar, WhatsApp, Slack, Telegram, Discord and other web apps in one window.

  • Read, write and organize Gmail for several accounts, using Google's official Gmail API.
  • See and edit Google Calendar events, using Google's official Calendar API.
  • Quiet notifications during calls and quiet hours.

Roost runs only on your own computer. It has no server and no user accounts.
